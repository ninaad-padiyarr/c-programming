    <h2>📂 Repository Structure</h2>
    <pre>
├── 2D arrays/                    # Two-dimensional array programs
├── advanced math/                # Mathematical operations (recursion, series)
├── basics/                       # Fundamental C programs
├── bubble sort, selection sort/  # Sorting algorithms
├── control-flow/                 # Control flow statements
├── function, stud-pass/          # Functions and student pass programs
├── linear, binary search/        # Search algorithms

└── structures/                   # Structures and custom data types

        <li><strong>Control Flow:</strong> If-else, Loops, Switch statements</li>
        <li><strong>Functions:</strong> Function declaration, definition, recursion</li>
        <li><strong>Arrays & Strings:</strong> Single and multi-dimensional arrays</li>
        <li><strong>Pointers:</strong> Pointer arithmetic, dynamic memory allocation</li>

    </ul>
